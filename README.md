# PurrSec Labs

PurrSec Labs is a fictional cybersecurity portfolio project designed for defensive-security education, UI/UX practice, and defensive tooling storytelling. It presents a glowing cyber cat-themed SOC dashboard with safe fictional data, simulated incident detection, and analyst workflows.

## Overview

PurrSec Labs is:

- educational
- defensive-security focused
- fictional
- portfolio-oriented

It offers a fictional SOC experience with threat intelligence, malware analysis, sandbox monitoring, and analyst team storytelling.

## Features

- Live-style SOC alert feed with severity badges and timestamps
- Animated terminal-style alert ticker
- Fictional phishing, ransomware, outbound traffic, and credential stuffing alerts
- Meowware Analysis dashboard with sandbox activity, process tree, and network connections
- Cat-themed analyst team profiles with certifications and specialties
- Responsive dark cybersecurity UI with subtle animations
- Static no-install version that runs directly in the browser

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Optional React/Vite source for advanced development

## Installation

This project can run without installing any dependencies.

### Quick start (no software required)

1. Open `index.html` in your browser.

### Optional development setup

If you want to explore the React/Vite source in the repository:

1. Install Node.js and npm.
2. Run `npm install`.
3. Run `npm run dev`.
